# TruongPaper icon assets

`truongpaper-icon.png` is the master application icon, generated with the built-in ImageGen tool. It replaces the previous TruongFlix icon. Platform sizes are produced with `npx tauri icon` and copied into `src-tauri/icons/`; `docs/app-icon.png`, `public/app-icon.png`, and `public/favicon.png` use the same design.

`tray-icon.svg` is a separate monochrome vector rendition of the layered-photo mark. Its transparent 22px PNG is used as the macOS menu-bar template, avoiding an opaque black icon tile.

## Final generation prompt

Use case: logo-brand. Asset type: production desktop application icon for TruongPaper, a photography and live wallpaper app with a simple charcoal dark interface. Generate a single square app icon, front-on, no presentation mockup. A refined rounded-square charcoal tile with a clean warm-white abstract stack of two photographic paper frames; the foremost frame contains one very simple mountain ridge and small sun, subtly suggesting a wallpaper picture and layered sheets of paper. Bold, calm, precise, highly legible at 32 pixels, generous internal spacing, minimal flat graphic design with only a very subtle edge highlight for depth. Charcoal, ivory, and restrained cool gray only. No text, no letters, no play triangle, no filmstrip, no neon, no glow, no busy details, no watermark. Exactly one centered icon, with transparent background outside the rounded-square tile. 1024 by 1024 composition.
